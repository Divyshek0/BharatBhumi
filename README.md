# BharatBhumi

This repository contains the Render Blueprint and Dockerfiles at its root. The application source is packaged in `bharatbhumi-render-package.zip`; each Docker build extracts only its service's files.

To deploy, open the repository in Render and create a Blueprint from `render.yaml`. Render will request `ADMIN_EMAIL` and `ADMIN_PASSWORD`; choose a unique admin account and a strong password. JWT and AI internal secrets are generated by Render.

All services use Render's free preview tier. Free web services can sleep while idle, and free Postgres expires after 30 days. Upgrade the database before relying on it to retain data. Details: https://render.com/docs/free.
